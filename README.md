# Portfolio

Personal site for Soleiman Arebi: a two-column dark layout covering AI oversight, nonlinear dynamics and complex networks.

- `index.html`: all content (about, research, experience, publications)
- `content.js`: all text. Each entry in `FILES` is one tab. Lines marked `‹todo|…›` are placeholders to fill from the CV.

No build step. Netlify publishes the repo root (`netlify.toml`).
